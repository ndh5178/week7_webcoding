⚡ WHERE id = 500000 — 흐름
1 SQL 파서: WHERE 컬럼이 id → 인덱스 모드
2 B+ 트리 루트에서 500000 탐색 시작
3 루트 → 내부 노드 → 리프 (3~4단계)
4 리프에서 레코드 포인터 반환 → 즉시 출력
🐌 WHERE name = 'T1 Faker' — 흐름
1 SQL 파서: WHERE 컬럼이 name → 선형 모드
2 table[0].name 비교 → 다름 → 다음
3 table[1].name … table[898999].name → 전부 다름
4 table[899000].name == 'T1 Faker' → 반환
